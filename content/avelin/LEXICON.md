# Avelin — Core Lexicon 1.0

Read with GRAMMAR.md. This is a seed lexicon, not a dictionary large enough for every subject. Regular derivatives are not separate roots. Vowel quality, syllabification, and penultimate stress follow the grammar without exceptions. N = noun; A = adjective; V.i = intransitive; V.t = transitive; V.c = complement-taking. Accusative objects are marked -n. Optional arguments may remain unspecified under §5.2.

## Time adverbs

`nua` now; `era` yesterday; `ora` tomorrow. Adverb formation from adjectives uses -si. All closed-class items, numerals, pronouns, and affixes are defined normatively in the grammar; this lexicon supplements rather than replaces those tables.

## Naming and extension

A new ordinary root should end in a vowel, obey (C)V(C), and receive a class and argument frame. Proper names may use permitted final codas. Derive predictable words before inventing new roots, but avoid excessively long chains. Check homophones before adopting a root; deliberate homophony must be documented. Technical and cultural meanings should be explicitly introduced, not assumed to be native traditions.
